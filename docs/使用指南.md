# 安装与日常使用指南

适用子豪日记 1.2.8；Halo 版本声明 >= 2.27.2，当前实际验证基于 2.27.2。

## 1. 安装、升级和回退

1. 从 Releases 下载 `theme-hao-diary-1.2.8.zip`，不要使用 GitHub 的 Source code 压缩包。
2. 登录自己站点的 `/console`，打开“外观 → 主题 → 主题管理 → 上传安装 / 升级”。
3. 选择 ZIP；遇到“主题已存在，是否升级”时确认。
4. 首次安装启用“子豪日记”；升级后核对启用状态与版本号。
5. 检查首页、菜单、文章和图片。必要时强制刷新浏览器缓存。

升级前保存旧 ZIP 并记录自己的主题设置。需要回退时上传上一版 ZIP，并检查字段兼容性；不要为了回退主题重建容器或直接恢复全库。

## 2. 首次配置清单

- 系统基本设置中填写站点标题、描述与图标。
- 在“外观 → 菜单”维护导航，再在主题“基础信息”选择菜单。
- 创建自己的文章、分类和页面；主题不导入演示内容。
- 主按钮 `/#posts` 定位文章列表；`/about-me` 等页面地址需自行创建或修改。
- “辅助栏”填写头像、昵称、简介与社交链接；空值显示占位提示或隐藏链接。
- 调整页脚文案和署名；备案信息仅填写自己实际使用的信息。

## 3. 首页首屏与背景

入口：“主题设置 → 首页首屏”。

- 可关闭首屏，编辑眉题、主标题、第二行、说明与两个按钮；第二按钮文字留空可隐藏。
- 单行诗句按可用宽度适配字号，建议控制文案长度。
- 自选背景图可以调整遮罩和透明度；未指定图片时使用内置原创 SVG。
- 背景轮换按访问策略工作，不是定时自动播放的幻灯片；开启后维护图片列表。
- 波浪可关闭或保持静止，并可调整高度和运动周期。

背景与头像先上传到自己 Halo 的附件管理，再将可访问的地址用于配置。源码不额外分发演示站点的原始壁纸、头像和文章图片。

## 4. 列表与辅助栏

桌面端（宽度 > 700px）辅助栏随页面下滚后，停留在顶部导航下方。1.2.8 起，封面滚出视野后顶部导航带动效收起，回到封面时恢复；此时辅助栏吸顶间距自动缩至 24px。侧栏内容过长时，将鼠标移入侧栏滚动，或按 Tab 聚焦“博客辅助栏”后使用方向键查看下方模块。滚动到列表末尾时，侧栏随内容容器结束，不覆盖页脚。手机端维持普通文档流，辅助栏位于文章列表后。无需在后台额外打开开关。

“文章列表”调整卡片高度、封面比例与标签显示。封面读取文章自身设置；未设封面或图片失效时退回纯文字卡片，不自动补插画。

“辅助栏”配置个人资料、分类、推荐链接与运行时间，并调整模块顺序、启用状态。建站日期填写真实日期，也可留空。

## 5. 正文、目录和插件

- “字体与阅读”控制字号、行高、目录开关和标题层级。
- 目录从正文真正的标题生成；普通加粗段落不等于标题。
- 桌面目录位于侧边，手机通过“查看本文目录”展开；没有有效目录时不占用侧栏。
- 代码高亮依赖相应 Halo 插件；主题提供布局与横向滚动样式。
- 灯箱需要已安装且兼容的插件。`gallery-controls.js` 对已有 PluginLightGallery 1.x 做滚轮缩放/拖动平移适配，不负责安装插件。
- 图表效果取决于编辑器和渲染插件；已有验证包含 ByteMD 1.10.0 生成的 Mermaid SVG，主题不额外启动 Mermaid 渲染器。

## 6. 动效与滚动

“动效”可关闭首页入场和加载动画，调整首页时长。文章进出采用固定的轻量时长，与首页分层入场时长不是同一项。

- 最多动画 8 个可见元素，总面积不超过两个视口。
- 滚轮、触屏、指针或键盘输入取消当前文章过渡。
- 浏览器后退保留列表位置，站内返回不重播首页加载动画。
- 系统“减少动态效果”优先于后台动效设置。

遇到卡顿先确认版本、浏览器和插件，分别检查第三方脚本、图片大小和网络。不要直接恢复整屏快照、逐帧写历史或滚动时大量预取页面。

## 7. 常见问题

| 现象 | 检查方式 |
| --- | --- |
| 安装包不完整 | 确认使用 Release 主题 ZIP，而不是 Source code |
| 没有截图里的内容 | 文章、菜单、头像和背景属于站点数据，需自行配置 |
| “关于我”打不开 | 创建页面并确认固定链接，或修改按钮地址 |
| 修改源码没有变化 | 重新构建并上传；新资源同时更新查询版本 |
| 没有文章过渡 | 检查动效、减少动效、是否站内导航和是否有输入取消过渡 |
| 图片没有灯箱 | 检查兼容插件及初始化状态 |
| 后台显示缺少 layout.html | 当前不实现该布局契约；相关页面可能使用 Halo fallback |
| GitHub Pages 不显示博客 | 本主题需要 Halo 服务端数据与 Thymeleaf 渲染 |
