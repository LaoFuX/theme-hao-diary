# 开发维护指南

## 构建约定

Node.js >=22.12.0，pnpm 固定 10.28.2，解析结果以锁文件为准。先执行 `npx --yes pnpm@10.28.2 install --frozen-lockfile`，再执行 `npx --yes pnpm@10.28.2 run build`。

- `src/pages/*.astro` 组装组件和 `src/layouts/Shell.ts`。
- `public/assets/` 是定制 CSS、配置读取和交互脚本入口。
- `templates/`、`dist/`、`.astro/` 不手改、不提交。
- 保留 ui-plugin 工作区与锁文件，当前页面不加载该上游 UI；主主题不要求运行 build:ui-plugin。
- 新增后台字段同步修改 `settings.yaml` 与 `默认设置.json`，不把生产站点数据写入默认值。
- 资源修改时更新 Shell.ts/Hero.ts 查询版本，发版同步更新 theme.yaml。

## 回归检查

主题没有覆盖整套定制页面的自动化测试套件；上游 ui-plugin 测试不等于页面验收。

1. 对修改的 JS 执行 `node --check`。
2. 完整构建，确认 ZIP 中有主题信息、设置、许可证、模板及资源。
3. 在测试 Halo 安装，检查首页、分类、分页、文章和独立页面。
4. 检查桌面与 390px 手机宽度的菜单、目录、图片及横向溢出。
5. 验证文章进入、上下篇、首页返回、浏览器前进后退和列表位置。
6. 滚轮上下滚动，确认过渡可取消，没有滚动锁定、反复跳位或长时间半透明。
7. 减少动效时关闭动画，站内返回不重播加载动画。
8. 已使用的灯箱和代码高亮等插件在完整导航后正常初始化。

## 动效性能约束

保留 1.2.4/1.2.6 已修复的路径：

- 不在每个滚动帧写 history.replaceState。
- 不在滚轮期间大量加载和解析多个列表页。
- 不恢复文章切换的整屏 View Transition 快照。
- 不给整篇长文章或整个 main 设置持续动画层。
- 不在滚轮经过时为所有卡片逐张启动位移入场。
- 输入立即取消短暂导航动画，尊重减少动效。

1.2.6 上限为 8 个可见元素、两个视口总面积。扩大范围后应重新测量，不能仅凭截图判断性能。

## 附件与源码边界

仓库不保存服务器 .env、SSH 私钥、数据库、生产配置快照或测试账号。个人配置和演示媒体单独维护。

`release-assets/` 是整理时附带的原始线上包；`dist/` 是当前源码重新构建的包。整理时补充了文档、预览图和开发配置，因此重建 ZIP 的文档、预览和哈希可与原始包不同；主题运行时代码保持一致。

以后新增功能应使用新版本号，发布对应提交构建的包，不混用旧附件。


## 1.2.7 辅助栏吸顶

样式位于 `public/assets/refinement.css` 的桌面媒体查询，选择器 `.layout>.side`。顶部偏移 100px，最大高度 `calc(100svh - 116px)`；子面板禁止 flex 压缩，超高内容原生滚动。`Sidebar.ts` 提供键盘焦点。不添加 scroll 监听、定时测量或 JS fixed 定位。若修改顶部导航高度，应同步检查此偏移。

验收：桌面下滚至少一屏、侧栏内部滚到底、分类切换与空分类、页面底部、Tab/方向键、390px 手机和“往下看看”按钮。


## 1.2.8 顶部导航收起

`public/assets/header-collapse.js` 只在存在封面的页面启动。IntersectionObserver 以视口顶部 24px 为边界，切换根元素 `data-header-collapsed`；仅初始化和 pageshow 缓存恢复时各读取一次封面几何信息。pagehide 断开观察。隐藏导航使用 inert 和 aria-hidden；菜单展开或导航持有焦点时暂缓收起。

`refinement.css` 用 transform/opacity 执行 240ms 动效，不缩放高度、不改变文档流。系统减少动效或主题关闭动效时直接切换。`--sidebar-top` 在展开/收起时为 100px/24px；列表锚点 scroll-margin-top 为 24px，listing-navigation.js 在定位时读取该值，保留无脚本/无观察器环境的 100px 回退。

验收覆盖封面下滚/返回、首页锚点、直接刷新 #posts、分类切换、手机布局、减少动效、详情页导航和浏览器后退。避免改为每次滚轮计算位置，避免给整页添加 transform。
