# 子豪日记 1.2.8

顶部导航现在会在封面滚出视野后上滑淡出，回到封面时展开。左侧辅助栏同步靠近顶部，消除导航收起后的大块留白；首页“往下看看”与分类定位保持正常。文章详情页导航行为保持原样。

采用 IntersectionObserver 通知边界变化，没有新增 scroll 监听、轮询和逐帧几何测量。尊重减少动效/关闭主题动效，保留文章过渡和历史滚动性能修复。

适用 Halo >= 2.27.2。下载 theme-hao-diary-1.2.8.zip，在“外观 → 主题 → 主题管理 → 上传安装 / 升级”上传并确认升级。升级前备份配置与旧版 ZIP；需要回退时上传原版本 ZIP。Source code 是源码，需构建后安装。
