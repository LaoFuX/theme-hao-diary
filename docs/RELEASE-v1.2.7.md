# 子豪日记 1.2.7

首页与分类等列表页的桌面左侧辅助栏现在可吸附在顶部导航下方。超高侧栏支持内部滚动与键盘聚焦，保留个人资料、分类及其他模块；手机端布局保持原样。

采用 CSS sticky，没有新增 JavaScript 滚动监听或轮询。沿用 1.2.6 的首页锚点修复，以及此前的文章过渡与滚动性能策略。

适用 Halo >= 2.27.2。下载 `theme-hao-diary-1.2.7.zip`，在“外观 → 主题 → 主题管理 → 上传安装 / 升级”上传并确认升级。升级前备份主题配置和旧 ZIP；需要回退时上传原版本 ZIP。GitHub 自动生成的 Source code 是源码，需要构建后才能安装。
