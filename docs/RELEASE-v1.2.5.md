## 子豪日记 1.2.5

### 更新内容

- 恢复进入文章、返回首页及浏览器后退的轻量过渡。
- 保留 1.2.4 的滚动修复，动画仅处理少量可见元素。
- 滚轮、触屏、指针和键盘输入取消当前过渡。
- 站内返回不重播首页加载动画，后退恢复列表位置。

### 安装

适用 Halo >=2.27.2，当前验证基于 Halo 2.27.2。下载附件 `theme-hao-diary-1.2.5.zip`，在 Halo 后台“外观 → 主题 → 主题管理 → 上传安装 / 升级”上传。升级前保留旧主题包和自己的配置记录。

自动生成的 Source code ZIP/TAR.GZ 是源码，需要构建后安装。主题不包含演示文章、背景或头像，也不捆绑灯箱与代码高亮插件。

### 验证范围

已验证构建和脚本语法、桌面/手机页面导航、滚动及返回位置、减少动效。性能检查为当前环境采样，不代表所有硬件、浏览器和插件组合。
